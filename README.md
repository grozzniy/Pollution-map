# Pollution-map
The map of pollution in Saint-Petersburg. Was created because I needed to complete my Life Safety laboratory work (and because same map that was given in this work wasn't working).

How to use this programm:
1. Download .zip archive with HTML file and overlays with pollution reflecting;
2. Unarchive it in comfortable directory;
3. Deploy API key at Yandex Maps;
4. Insert your API into HTML file;
5. Deploy your localhost server in the derictory where you unarhcived zip;
6. Enter link 'http://localhost:*/map.html' in browser where * - port of your server;
7. Enjoy!
